========================================================
 CÓMO INSTALAR ESTO EN TU REPOSITORIO "huecos"
========================================================

Esta carpeta trae 6 archivos. Todos van SUELTOS en la raíz
de tu repositorio (Observatorio2026/huecos), al mismo nivel
donde ya están index.html, admin.html e icono.png.
NO van dentro de css/ ni js/.

Archivos incluidos:
  1. manifest.json          -> nuevo
  2. sw.js                  -> nuevo
  3. icon-192.png           -> nuevo
  4. icon-512.png           -> nuevo
  5. icon-512-maskable.png  -> nuevo
  6. favicon-32.png         -> nuevo (opcional, ícono de pestaña)

--------------------------------------------------------
PASO 1 — Sube estos 6 archivos a la raíz del repo
--------------------------------------------------------
Opción fácil (sin usar terminal):
  a) Entra a https://github.com/Observatorio2026/huecos
  b) Botón "Add file" -> "Upload files"
  c) Arrastra los 6 archivos de esta carpeta
  d) Abajo, en "Commit changes", escribe un mensaje como
     "Agrega soporte PWA" y dale click en "Commit changes"

Opción con git (si ya clonas el repo en tu computador):
  cp manifest.json sw.js icon-192.png icon-512.png icon-512-maskable.png favicon-32.png /ruta/a/tu/repo/huecos/
  cd /ruta/a/tu/repo/huecos/
  git add manifest.json sw.js icon-192.png icon-512.png icon-512-maskable.png favicon-32.png
  git commit -m "Agrega soporte PWA para instalar como app"
  git push origin main

--------------------------------------------------------
PASO 2 — Edita tu index.html (y admin.html si quieres)
--------------------------------------------------------
Abre index.html en GitHub (ícono de lápiz para editar) y
busca esta línea que ya tienes en el <head>:

    <link rel="icon" href="icono.png" type="image/png">

Justo DEBAJO de esa línea, pega esto:

    <link rel="manifest" href="manifest.json">
    <link rel="apple-touch-icon" href="icon-192.png">
    <meta name="apple-mobile-web-app-capable" content="yes">
    <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
    <meta name="apple-mobile-web-app-title" content="Huecos">

Luego busca la última línea antes de </body>, que es:

    <script src="js/report.js"></script>

Justo DEBAJO de esa línea (todavía antes de </body>), pega:

    <script>
      if ('serviceWorker' in navigator) {
        navigator.serviceWorker.register('sw.js');
      }
    </script>

Guarda los cambios ("Commit changes" en GitHub, o git commit
+ git push si usas terminal).

--------------------------------------------------------
PASO 3 — Espera el despliegue
--------------------------------------------------------
Ve a la pestaña "Actions" de tu repo y espera a que el
ícono quede en verde (1-2 minutos). Eso confirma que
GitHub Pages ya publicó los cambios.

--------------------------------------------------------
PASO 4 — Prueba desde el celular
--------------------------------------------------------
Android / Chrome:
  Abre tu página -> espera unos segundos -> aparece el
  banner "Agregar a pantalla de inicio" o el botón de
  instalar en el menú de 3 puntos (⋮).

iPhone / Safari:
  Abre tu página -> toca el botón "Compartir" (el cuadrado
  con la flecha hacia arriba) -> "Agregar a pantalla de
  inicio".

En ambos casos queda un ícono como cualquier otra app, que
abre tu geovisor directo, sin barra del navegador.
